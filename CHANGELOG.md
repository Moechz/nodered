# Changelog

All notable user-visible changes to the Node-RED TOS application package.

## 5.0.9-1 — 2026-11-10

### Added
- First release. Node-RED (`nodered/node-red:5.0.9`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8043 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/nodereddocker/`.
